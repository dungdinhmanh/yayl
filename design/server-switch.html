MÁY CHỦ

Một icon game, nhiều máy chủ

Bấm icon game để mở hộp chọn máy chủ. Mỗi máy chủ là một profile riêng: version, thư mục cài, tiến trình tải.

Chọn máy chủ

Ý tưởng, chưa chốt. Có thể đổi cách hiển thị.

  • Icon game có badge máy chủ (EN/JP/KR) ở góc.
  • Bấm icon → popover danh sách máy chủ, có trạng thái cài / ping / version.
  • Giữ chuột hoặc right-click để mở nhanh; click thường để mở popover.
  • Máy chủ đang tải có viền tiến trình quanh icon.

Data model

gameId → { servers: [{ id, label, biz, apiHost, cdnHost, version, installed, path }] }

Mỗi máy chủ có manifest/config riêng. Chuyển máy chủ = đổi profile, không đổi file cài của máy chủ khác.
